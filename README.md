## Run the assembler

From this directory:

```bash
python assembler.py Box.asm
```

This creates `Box.hack`. To choose an output filename:

```bash
python assembler.py Box.asm output.hack
```

The assembler strips comments and blank lines, records labels in pass one, and translates instructions in pass two. New variables are allocated from RAM[16]. Duplicate label declarations produce a warning and retain the first definition.

## Box calculations

- Starting row: 70
- Height: 20 rows (70 through 89)
- Width: `16 * ((70 % 4) + 1) = 48` pixels
- Words per row: 3
- First screen word: `16384 + 32*70 = 18624`
- Next row: add 32 to the screen address

The program checks `KBD` continuously. A nonzero keyboard value draws `-1` to three consecutive screen words in each of 20 rows. A zero value writes `0` to those same words. This produces a 48-pixel-wide, 20-row-high rectangle.
